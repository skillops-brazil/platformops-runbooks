# Roteamento de desenvolvimento assistido por LLM

Este projeto usa a biblioteca de agentes em `.claude/artefacts/agents/` (sincronizada de ai-artefacts).
**Antes de responder ou codar**, roteie a tarefa:

- **AVALIAR / DECIDIR** (vale a pena? é seguro? arquitetura certa? qual o risco?)
  → painel `.claude/artefacts/agents/review/` via o subagent `supervisor-tecnico` (aciona só os domínios relevantes).
- **EXECUTAR / IMPLEMENTAR** (feature, bug, migração)
  → pipeline `.claude/artefacts/agents/build/` via o subagent `pipeline-build` (percorre só os estágios necessários e mantém o event log em `event-logs/`).

Não rode todos os agentes por padrão. Mudança pequena = 1-2 agentes.
Aplique sempre `.claude/artefacts/agents/_CONVENTIONS.md` (header YAML, tetos de achados, contexto filtrado).

**Artefatos de UX/design** ficam em `design/` (marca, tokens, wireframes, protótipos, componentes, assets). Ao trabalhar em UI, consulte e atualize `design/`; o coding deve reusar os tokens de `design/tokens/`, não recriar estilos. Para gerar/evoluir esses artefatos, use `.claude/artefacts/prompts/ux-design.md`.

**Commits** seguem `.claude/artefacts/agents/_COMMITS.md`: Conventional Commits, em português, título ≤ 72 chars, tipos `feat|fix|refactor|docs|test|chore|ci|build`, sem emojis e **sem qualquer referência a IA (`Co-authored-by`, `Generated by Claude` etc.)**.

O **contexto vivo deste projeto** está em [`context.md`](./context.md) — use-o como recorte de domínio; não assuma nada fora dele. **Todo agente que produzir mudança ou fato novo relevante atualiza o `context.md`** (só a seção afetada) e **escreve um resumo curto** — o contexto guarda resumos condensados, nunca material bruto (poupa tokens/janela).

**Primeira vez neste projeto?** Rode antes de tudo o prompt inicial de contexto: `.claude/artefacts/prompts/atualizar-contexto.md` — ele preenche o `context.md` com dados reais a partir do código e do guia de marca.
